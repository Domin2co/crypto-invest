# 접근성·웹 편의성 기준

- WCAG 2.2 AA를 목표로 키보드만으로 핵심 흐름을 완료하고, focus 상태·논리적 heading·label·오류
  메시지·ARIA 이름/역할/상태를 제공한다.
- 색상만으로 PAPER/LIVE, 성공/실패, 위험 상태를 전달하지 않는다. 텍스트·아이콘·명도를 함께 쓴다.
- 모바일 320px 이상에서 가로 overflow 없이 핵심 읽기·동의·권리·안전 상태를 확인할 수 있게 한다.
- 터치 대상은 충분한 크기와 간격을 두고, 실주문은 명확한 확인·취소 경로·현재 모드 표시를 제공한다.
- 화면 변경 시 desktop과 mobile viewport E2E, keyboard tab 순서, screen-reader 이름을 검토한다.
