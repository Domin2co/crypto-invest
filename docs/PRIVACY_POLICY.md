# 개인정보처리방침 초안

> 상태: 개발용 초안. 공개·유료 서비스 전 사업자 정보, 개인정보 보호책임자, 문의처,
> 보유기간·국외이전·수탁처를 확정하고 전문 법률 검토 후에만 게시한다.

## 처리 목적과 최소 항목

| 목적 | 항목 | 법적/서비스 근거 | 보유 |
| --- | --- | --- | --- |
| 회원 인증·표시 | 이메일, BCrypt 비밀번호 해시, 고유 닉네임 | 서비스 이용·계정 식별 | 탈퇴/익명화까지 |
| 거래소 연동 | 사용자별 암호화 API access/secret key | 사용자가 요청한 자산조회·주문 기능 | 계정 연결 해제·탈퇴 시 삭제 |
| 마케팅 | 수신 동의 여부·정책 버전·시각 | 별도 선택 동의 | 철회 또는 정책상 보유기간 종료까지 |
| 보안·감사 | 최소 주문 식별자·상태·오류 코드 | 부정사용 방지·사고 대응 | 법무 확정 보유기간까지 |

거래소 API key, 비밀번호, Authorization header, 요청 서명은 화면·응답·로그·내보내기에
포함하지 않는다. API key는 AES-256-GCM으로 암호화해 저장한다.

## 동의와 사용자 권리

- 가입 시 개인정보 처리 동의는 필수, 마케팅 수신 동의는 선택이다. 선택 거부가 가입·핵심
  기능 이용을 제한하지 않는다.
- `GET /api/privacy/me`: 본인 이메일과 동의 이력 열람/내보내기.
- `PATCH /api/privacy/marketing-consent`: 마케팅 수신 동의·철회.
- `DELETE /api/privacy/me`: 로그인 차단, 거래소 자격증명 삭제, 직접 식별정보 익명화.
- 정정·처리정지·완전 삭제·이의제기는 운영 문의 경로와 법정 절차/기한을 법무 확정 후
  별도 제공한다. 법령상 보존 의무가 있는 거래·감사 기록의 처리 방식은 출시 전에 확정한다.

## 변경 관리

정책 변경마다 `PRIVACY_POLICY_VERSION`을 올리고, 새 처리 목적·제3자 제공·국외이전은
필요한 재동의와 법무 검토를 거친다.


## 선택 동의: 월간 모의거래 랭킹 공개

월간 모의거래 랭킹 참가 시 닉네임, 대회 월, 월간 수익률, 체결 수, 순위와 메달을 공개할 수 있다. 가입·서비스 이용을 위한 필수 동의가 아닌 별도 선택 동의이며, 동의하지 않아도 나머지 기능을 이용할 수 있다. 이메일과 가상 잔액은 공개하지 않는다. 계정 화면에서 언제든 철회할 수 있으며, 철회하면 참가와 결과 기록을 삭제한다. 동의 버전과 시각은 다른 동의와 분리해 기록한다.
## 종목별 공개 토론방

토론방을 이용하면 종목 기호, 게시글 본문, 작성 닉네임과 생성 시각을 토론방 이용자에게 공개한다. 이메일과 계정 ID는 공개하지 않는다. 게시글은 계정 삭제 요청 시 함께 삭제한다. 게시글에 비밀번호, 거래소 API key 등 민감정보를 입력하지 않도록 화면에서 안내한다. 공개 서비스 출시 전 보유·삭제·신고 대응 절차를 법률·개인정보 검토로 확정한다.

### 이메일 인증 정보

가입 및 이메일 변경을 위해 이메일 인증 코드를 일시 보관합니다. 코드는 10분, 확인 완료용 1회 토큰은 15분 후 만료되며 데이터베이스에는 원문 대신 HMAC 해시만 저장합니다. 만료 후 24시간이 지난 인증 기록은 매일 삭제합니다. 가입일과 이메일 변경 시각은 90일 변경 제한 적용에 사용합니다.
