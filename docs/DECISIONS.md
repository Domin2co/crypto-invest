## ADR-006 — Recommendation 평가 결과는 재현 가능한 자산 스냅샷으로 저장한다

### 상태

결정됨

### 결정

자산 평가는 서명 점수, 신뢰도, 시장 레짐, 규칙 버전, 지표/요인/데이터 품질 스냅샷을 시각과 함께 기록한다. 사용자 포트폴리오 액션과 주문 실행은 별도 경계로 유지한다. 공개 무료 데이터에서 확보되지 않은 지표는 값으로 추정하지 않고 unavailable 상태로 나타낸다.

### 이유

- 동일 시점 입력에 대한 추천 재현과 과거 결과 평가 지원
- 결측/낡은 데이터로 인한 가짜 확신 방지
- 추천 계산이 사용자 자산이나 주문 상태를 변경하지 않도록 보장
