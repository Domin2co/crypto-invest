# 공개 서비스·유료/타인 자동매매 준법 게이트

> 이 문서는 법률 자문이 아니다. 대한민국 기준으로 작성한 출시 차단 목록이며, 실제 서비스
> 제공 전 변호사·개인정보 보호 전문가·거래소 정책 검토가 필수다.

## 출시 차단 게이트

- [ ] 사업자, 개인정보처리자, 개인정보 보호책임자, 고객 문의·분쟁·환불 절차 확정
- [ ] 개인정보처리방침/이용약관/마케팅 동의 문안 및 보유·파기·위탁·국외이전 여부 법률 검토
- [ ] 개인정보 영향평가·보안 위험평가 필요성, 침해사고 통지·대응 절차 검토
- [ ] 유료 추천·자동매매·타인 계정 주문의 인허가/신고/등록·광고·소비자보호 적용성 검토
- [ ] 거래소 API 약관, 주문 권한, 출금 금지, rate limit 및 사용자별 동의 확인
- [ ] 수익/손실 보장·오인 표현 금지와 위험고지, 취소·환불 정책 확정
- [ ] 독립 보안 점검, 접근성 점검, 장애·복구 훈련, LIVE 승인 기록 완료

개별성 있는 유료 조언과 타인 재산의 주문 실행은 규제 적용 가능성이 특히 크다. 자본시장법상
투자자문·투자일임 및 유사투자자문업의 적용 여부를 사업모델·대상 자산·대가·개별성 기준으로
전문가가 판단해야 한다. [국가법령정보센터 자본시장법 제6조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1027642775),
[제101조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1017472761)를 참고한다.

개인정보 수집·이용 동의 및 열람/정정/삭제 권리는 [개인정보 보호법 제15조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335387),
[제35조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900079319)를 기준으로 검토한다.
