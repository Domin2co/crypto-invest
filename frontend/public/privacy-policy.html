개인정보처리방침

상태: 개발용 초안입니다. 공개 또는 유료 서비스 전 사업자 정보, 개인정보 보호책임자, 문의처, 보유기간 및 수탁/국외이전 사항을 법률 검토 후 확정합니다.

수집·이용 목적과 항목

  • 회원 인증: 이메일과 암호화된 비밀번호 해시
  • 거래소 연동: 사용자가 등록한 암호화 API key. 화면·응답·로그에는 노출하지 않습니다.
  • 선택 마케팅: 수신 동의 여부, 정책 버전, 동의/철회 시각

이용자 권리

가입 뒤 내 정보에서 개인정보와 동의 이력을 열람하고, 마케팅 수신을 언제든 철회할 수 있습니다. 계정 삭제는 API key 삭제와 직접 식별정보 익명화를 수행합니다. 법령상 보존 대상의 처리 기준과 연락처는 정식 정책에서 고지합니다.

상세 개발 정책: 프로젝트의 docs/PRIVACY_POLICY.md를 참고합니다.
